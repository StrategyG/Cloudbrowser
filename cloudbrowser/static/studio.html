MorphGLB AI Studio 3D v3.3.0

Editor mesh, rig dan animasi 3D berjalan di dalam Cloudbrowser tanpa mengganti pipeline Studio/Godot. Editor dipisahkan dari sesi akun dan API agent untuk keamanan.

Mode lokal: export GLB/PNG/JSON melalui tombol editor; layanan AI opsional di dalam HTML belum terhubung langsung dengan API Cloudbrowser. File dapat ditransfer ke katalog di bawah.

Kirim hasil editor ke Cloudbrowser

Setelah ekspor, pilih file hasilnya. GLB tervalidasi dapat memasuki pipeline Studio/Godot melalui persetujuan mesh, rig dan manifest. GLB rigged harus memiliki bone yang kompatibel; kualitas visual tetap perlu pemeriksaan manusia.
